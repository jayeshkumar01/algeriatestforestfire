How it works

From field reading to FWI score

Temperature, relative humidity, wind speed, rainfall and fuel-moisture codes are scaled with the same StandardScaler fitted during training, then passed through the Ridge regression for a continuous index.

01

Enter conditions

Temperature, relative humidity, wind speed, rainfall, and fuel-moisture codes (FFMC, DMC, ISI) for a given day and region.

02

Inputs are standardized

Values are scaled using the same scikit-learn StandardScaler fitted during training, so every feature is on comparable ground.

03

Ridge regression scores it

The trained model returns a Fire Weather Index — a continuous measure of fire intensity potential for that day.

Two models

Complementary approaches

RidgeCV predicts a continuous score; the Decision Tree makes a binary Fire / Not-fire call with interpretable depth.

A

FWI score — continuous

RidgeCV regression over 9 features. Output ranges roughly 0–30+, higher values meaning greater fire risk.

B

Fire risk — binary

Decision Tree with max_depth=3, using 10 features (includes DC and BUI). Fast, simple, interpretable.

C

Both regions

Trained on Bejaia and Sidi Bel-abbes data, with Region supplied as an input feature.
